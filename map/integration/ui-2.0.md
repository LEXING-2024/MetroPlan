# 界面 2.0：玻璃表面、可展开面板与性能降级

![HUD 与地图](../preview/ui2-hud.png)

这一版把界面收成一套可复用的“暖色玻璃”表面，并把交互反馈、右侧面板和低帧率降级一起处理。

## 表面系统

`src/style.css` 里定义令牌，`src/ui-v2.css` 只做覆盖，便于回退：

- `--glass-bg` / `--glass-bg-strong`：半透明暖纸色渐变；
- `--glass-blur`（18px）与 `--glass-sat`：统一背景模糊；
- `--glass-border` / `--glass-hi`：1px 冷灰边框 + 顶部高光；
- `--shadow` / `--shadow-soft` / `--shadow-pop`：三级阴影；
- `--ease` / `--ease-spring`：统一缓动。

同类型浮层复用 `.popover`（图层、票价、建站预览、组团信息）；关闭按钮复用 `.ui-close` / `.panel-close`，样式与旋转反馈一致。

## 顶栏

- 顶栏上移到 `top: 10px`，高度 64px；
- 背景模糊提高到 `blur(28px) saturate(1.42)`，底色透明度降到 0.62 / 0.48；
- 每个指标左侧增加 15px 线性图标（基金 / 人口 / 客流 / 行程 / 运营 / 净利 / 票价 / 通勤），窄屏自动缩到 13px；
- 数值区仍按 90ms 节流刷新，不跟随渲染帧重排。

## 工具栏

- 只显示图标，不再有“查看 / 建站 / 画线”文字，也没有右侧常驻的模式说明条；
- 悬停图标时在右侧显示一条毛玻璃提示，说明操作和快捷键；
- 选中块是深色毛玻璃（半透明渐变 + `blur(13px)` + 顶部高光），切换工具时平滑滑到对应位置；
- 即使系统开启“减少动态效果”，也保留 0.24s 的短滑动，否则这个反馈会完全消失。

## 右侧面板

- `.panel` 改为纵向 flex：标题栏固定，`.panel-scroll` 独立滚动；
- 关闭按钮绝对定位在右上角，滚动时不动；
- 面板先按内容自然展开；只有放不下时才出现底部渐隐与自绘滚动条 `.panel-rail`（不依赖浏览器原生滚动条样式）；
- 站序和列车运行区间默认收起：
  - 线路超过 10 站时显示“站序 · N 站”，点开后展开；
  - 列车区间显示“列车运行区间 N”，点开后编辑；
- 这样 1366×768 下 41 站的线路面板仍能完整显示所有统计与操作按钮。

![线路面板](../preview/ui2-line.png)

## 首页

- 不再使用右侧菜单列，标题、说明、统计和入口全部贴左；
- 入口横向排列：一个主按钮 + 三个文字链接，去掉每条下面的说明文字；
- 只保留“出行个体”和“一个游戏日”两个统计，页脚贴底；
- 标题、说明、统计与入口依次淡入，减少“整块卡片”的堆叠感。

![首页](../preview/ui2-menu.png)

## 性能

1. **HUD 刷新节流**：`GameUI.update()` 每 90ms 才做一次 DOM 更新，避免 60fps 下反复查询/写入。
2. **后台路径预算**：`processBackgroundRoutes(16, 3)` 每 tick 最多 3ms；先剔除已结束的后台行程，再决定是否跑 A*。
   - 修复前：早高峰队列 3,600+，帧率掉到 11–12 FPS；
   - 修复后：同一场景 86 FPS，队列会持续下降。
3. **自动降级**：连续 1.5s 低于 30 FPS 时给 `body` 加 `perf-saver`，关闭背景模糊与深阴影；回到 50 FPS 以上 6s 后恢复。
4. `prefers-reduced-motion` 下关闭入场动画；工具栏选中块单独保留短滑动。
