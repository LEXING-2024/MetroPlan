# 住宅点标注与人口密度（不画轮廓）

状态：已接入游戏。**住宅不再绘制任何范围轮廓**，改为真实村落/社区点标注；人口仍按真实住宅数据/建筑面积分配到点所在区域。

![住宅点标注，不画轮廓](../preview/residential-areas.png)

## 处理原则

- **不画住宅轮廓**；
- **“镇街余部”不当作住宅区**：`derived: true` / `镇 / 街道余部` 的单元不再生成住宅区 zone，也不生成兜底住宅面；
- **没有住宅面的村落**不伪造大面，改用 `places.geojson` 的真实村/社区点标注；
- **人口**继续用真实 OSM population 标签 + 住宅楼层面积/村落面积计算，再分配到住宅 cell。

## 标注来源

| 来源 | 数量 | 用途 |
|---|---:|---|
| `places.geojson` 真实村/社区点 | 592 个 in-bounds | 主标注 |
| 有名称小区中心 | 477 个补充 | 小区标注 |

标注不是住宅轮廓：只画小棕点；名称沿用底图标签，不再叠加 1,000 个 Pixi Text。

## 住宅数据

- 824 个 `landuse=residential` 面；
- 643 个小区/住宅用地；
- 267 个村落建成区面；
- 合并成 1,109 个住宅区域用于人口/密度计算；
- 90 个无真实住宅面的非余部村落按单元住宅面积生成兜底人口，但**不绘制轮廓**；
- 30 个“余部”单元完全排除出住宅 zone/区。

### 2. 区内分配

- **12 个 OSM population 标签**固定为真实值（82,218 人）；
- 每个区县剩余人口按住宅楼层面积/村落面积权重分配到区内住宅区域；
- 分配后做密度约束：
  - 最小有效面积 **0.02 km²**；
  - 密度上限 **80,000 人/km²**。

当前：

```text
住宅区域人口：1,120,582
  OSM 标签：   82,218 / 12 个
  floor-area：577,195 / 406 个
  area-density：461,169 / 691 个

M1 代表性常住人口：1,120,039
密度中位数：691 人/km²
P90：20,261 人/km²
上限：80,000 人/km²
```

**真实性说明**：

- 区县总量、12 个 OSM 标签是真实数据；
- 区县内部的住宅人口分配仍是模型，不是逐村普查；
- 因此这比之前 42 万更接近真实，但**不能当成逐小区真实人口**。
